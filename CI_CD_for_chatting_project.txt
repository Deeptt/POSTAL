📅 Week 1: Foundations
Focus: Git + Jenkins basics

Day 1–2: Create GitHub repo, set up branching strategy, push starter Java project.

Day 3–4: Launch free‑tier EC2 (t2.micro), install Jenkins.

Day 5–6: Configure Jenkins plugins (Git, Maven, Docker, AWS CLI).

Day 7: Create a simple pipeline job that checks out code and runs mvn clean test.

📅 Week 2: Build & Containerization
Focus: Docker + ECR

Day 8–9: Write Dockerfile for Java app (OpenJDK base, copy JAR, expose port 8080).

Day 10: Test Docker build locally (docker build, docker run).

Day 11–12: Set up AWS ECR repo (free tier covers 500 MB).

Day 13–14: Update Jenkins pipeline to build Docker image and push to ECR.

📅 Week 3: Deployment (Free Tier Path)
Focus: EC2/ECS deployment

Day 15–16: Write Ansible playbook to configure EC2 (install Docker, AWS CLI).

Day 17–18: Deploy container on EC2 (docker run -d -p 8080:8080).

Day 19–20: Optionally set up ECS task definition (free tier).

Day 21: Expose app via EC2 public IP or ECS service.

📅 Week 4: Scaling, Monitoring & Security
Focus: Optimization

Day 22–23: Configure EC2 Auto Scaling (free tier eligible).

Day 24–25: Set up CloudWatch metrics and alarms (basic free).

Day 26: Store secrets in AWS Systems Manager Parameter Store (free).

Day 27–28: Add CloudWatch Logs integration.

Day 29: Enhance Jenkins pipeline with integration tests and rollback.

Day 30: Final review — test full flow: Git commit → Jenkins build → Docker → ECR → EC2/ECS → CloudWatch.
